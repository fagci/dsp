# DSP workbench — заметки для Claude

## Работа с git
- Разработка — в ветке, которую задала сессия; после пуша **всегда создавай PR** (в `main`), даже если не просили.
- Перед созданием PR проверь, что предыдущий PR из этой ветки влит: `list_pull_requests` (head = ветка). Если влит — начни ветку заново от свежего `main` (`git fetch origin main && git checkout -B <ветка> origin/main`), не наслаивай коммиты на влитую историю. Если не влит — допиши в тот же PR, новый не создавай.
- Созданный PR сразу вливай (`merge_pull_request`), но **только свои свежие** — открытые тобой в этой сессии. Чужие и старые PR не трогай. Есть конфликты — сначала слей `main` в ветку и перештампуй (`node tools/stamp.mjs`), потом вливай.
- Коммиты и описания PR — по-русски, коротко, в стиле истории (`git log --oneline`).

## Перед коммитом
- Правил файлы оболочки (`*.js`, `styles.css`, `index.html`, `modules/*`…) — выполни `node tools/stamp.mjs` (версия = хэш файлов, прописывается в `sw.js` и `index.html`), потом `node tools/test-version.mjs`.
- **Версии обязательно повышай, если нужно.** Скрипты/оболочка: `stamp.mjs` (выше) — без него у пользователей останется старый кэш сервис-воркера. Пресеты: правил `presets.js` или состав/параметры пресетов — подними `PRESET_VER`, иначе сохранённые у пользователей пресеты не обновятся.
- Тесты — отдельные скрипты: `node tools/test-<имя>.mjs` (без раннера, DOM не нужен; код модулей грузится через `vm`).

## Карта проекта
Без сборки: статичный PWA, скрипты подключаются из списка `L` в `index.html`, кэшируются списком `SHELL` в `sw.js`. Новый файл — добавь в оба.
- `core-graph.js` — холст, узлы, провода (`drawWires`, `curve`, `bundleCurves`), выделение, undo, тулбар, дашборд/тайлы.
- `core-engine.js` — движок: топосортировка, обработка блоков, `portsOf`, типы портов.
- `core-dsp.js` — общие DSP-функции; `core-islands.js` — островки/воркеры.
- `modules/*.js` — модули (`def({id,title,cat,ins,outs,params,process,…})`); `*-kernels.js` — чистая логика без DOM (её и тестируют).
- `presets.js` — встроенные пресеты и патчи (при изменении — `PRESET_VER`, см. выше).
- `*-worker.js`, `vendor/` (wasm, библиотеки), `data/` — воркеры, внешнее, данные.
- `README.md` — список возможностей по разделам; новую фичу описывай там же.
- Поиск: `grep -n "id:'имя'" modules/*.js` — модуль по id; `grep -n "<id=\"…\"" index.html` — кнопка тулбара.
